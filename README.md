# 빌드 없이 실행

### 요구 사항
이 프로젝트를 실행하려면 다음 환경이 필요합니다.
1. **[Docker](https://www.docker.com/)**: MySQL 및 Redis 서버 실행 환경
### 실행
소스 코드를 직접 빌드하는 과정 없이 바이너리로 즉시 구동할 수 있습니다.
1. 우측의 **[Releases]** 탭에서 압축 파일(`Release.zip`)을 다운로드하고 압축을 풉니다.
2. 프로젝트 최상단에 있는 `ServerStart.bat` 파일을 더블 클릭합니다.

   *(도커 컨테이너, 3종의 서버, 모니터링 클라이언트, 더미 클라이언트가 자동 실행됩니다.)*
3. 더미 클라이언트에 `0`~`9` 사이의 숫자를 입력하여 접속할 **ID 리스트 그룹**을 선택합니다.

> ⚠️ **주의 (포트 충돌 방지):** 
> 로컬 컴퓨터에 이미 **MySQL(`3306` 포트)**이나 **Redis(`6379` 포트)**가 설치되어 실행 중인 경우, Docker 컨테이너 실행 시 포트 충돌이 발생할 수 있습니다. 
> Docker 구동 전에 로컬에서 실행 중인 MySQL 및 Redis 서비스를 잠시 중지해 주세요.
>
> ⚠️ **더미 클라이언트(Dummy Client) 다중 실행 시 주의사항**
> 더미 클라이언트는 실행 후 화면에서 `0`~`9` 사이의 숫자를 입력하여 접속할 **ID 리스트 그룹**을 선택해야 합니다.
> 2개 이상의 더미 프로그램을 띄울 때, **서로 같은 그룹 번호를 선택하면 중복 접속으로 처리되어 클라이언트가 다운(연결 종료)**됩니다. 다중 부하 테스트 시에는 반드시 각 창마다 다른 번호를 할당해 주세요.
>

## 시작
### 도커 컨테이너 구동

이 프로젝트는 데이터베이스(MySQL)와 인메모리 캐시(Redis)를 Docker 컨테이너로 구동합니다. 
저장소 최상단에 포함된 `docker-compose.yml`을 사용하여 손쉽게 환경을 구성할 수 있습니다.

프로젝트 루트 디렉터리에서 아래 명령어를 실행하여 컨테이너를 백그라운드에서 시작합니다.

```bash
docker-compose up -d
```

### 1. 소스 코드 빌드하기
코드를 직접 확인하고 디버깅하려면 아래 과정을 거쳐 빌드합니다.

1. 프로젝트를 클론한 뒤 Visual Studio에서 솔루션을 엽니다.
2. 솔루션 전체 **빌드(Ctrl+Shift+B)**를 진행합니다.
   * **초기 빌드 안내:** 처음 빌드 시 `vcpkg`가 종속된 라이브러리(MySQL, Redis 등)를 자동으로 다운로드하고 컴파일하므로 **약 5~10분 정도 소요**될 수 있습니다. (최초 1회만 소요)
---

### 2. 프로젝트 실행하기
테스트 목적과 환경에 맞춰 아래 세 가지 방법 중 하나를 선택하여 실행해 주세요.

#### 2.1. 배치 스크립트(`.bat`)로 한 번에 실행
프로젝트 최상단에 있는 `ServerStart.bat` 파일을 더블 클릭합니다.

   *(도커 컨테이너, 3종의 서버, 모니터링 클라이언트, 더미 클라이언트가 자동 실행됩니다.)*

#### 2.2. 실행 파일(`.exe`) 직접 수동 실행
원하는 서버나 클라이언트만 개별적으로 켜고 싶을 때 경로로 들어가 직접 실행합니다.
* **서버 프로세스:** `bin\x64\..` 경로의 `LoginServer.exe`, `ChatServer.exe`, `MonitorServer.exe`
* **모니터링 클라이언트:** `Clients\MonitoringClient_20241225\MonitoringClient.exe`
* **더미 클라이언트:** `Clients\ChatDummy_Loginserver_20221114\ChatDummy_Login_20221114.exe`

#### 2.3. Visual Studio에서 직접 실행 (디버깅)
코드 수정 및 디버깅을 위해 에디터 내에서 구동하는 방법입니다.
1. '솔루션 탐색기'에서 최상단 솔루션 우클릭 -> **[속성]**
2. **[공통 속성]** -> **[시작 프로젝트]** 메뉴 진입
3. **[여러 개의 시작 프로젝트]**를 선택하고 { ChatServer, LoginServer, MonitorServer } 를 **[시작]**으로 변경한 뒤 **F5**를 눌러 실행합니다.

> ⚠️ **더미 클라이언트(Dummy Client) 다중 실행 시 주의사항**
> 더미 클라이언트는 실행 후 화면에서 `0`~`9` 사이의 숫자를 입력하여 접속할 **ID 리스트 그룹**을 선택해야 합니다.
