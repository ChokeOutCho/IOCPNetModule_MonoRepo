## 준비

### 요구 사항
이 프로젝트를 빌드하고 실행하려면 다음 환경이 필요합니다.

1. **[Docker](https://www.docker.com/)**: MySQL 및 Redis 서버 실행 환경
2. **[vcpkg](https://github.com/microsoft/vcpkg)**: C++ 패키지 관리자 
   * C++ 애플리케이션에서 데이터베이스와 통신하기 위한 **MySQL 및 Redis C++ 클라이언트 라이브러리(예: `libmysql` 등)**를 설치하는 데 사용됩니다.
   * [vcpkg 설치 및 사용법 가이드 (Microsoft 공식 문서)](https://learn.microsoft.com/ko-kr/vcpkg/get_started/overview)

### 도커 컨테이너 구동

이 프로젝트는 데이터베이스(MySQL)와 인메모리 캐시(Redis)를 Docker 컨테이너로 구동합니다. 
저장소 최상단에 포함된 `docker-compose.yml`을 사용하여 손쉽게 환경을 구성할 수 있습니다.

프로젝트 루트 디렉터리에서 아래 명령어를 실행하여 컨테이너를 백그라운드에서 시작합니다.

```bash
docker-compose up -d
```
> ⚠️ **주의 (포트 충돌 방지):** 
> 로컬 컴퓨터에 이미 **MySQL(`3306` 포트)**이나 **Redis(`6379` 포트)**가 설치되어 실행 중인 경우, Docker 컨테이너 실행 시 포트 충돌이 발생할 수 있습니다. 
> Docker 구동 전에 로컬에서 실행 중인 MySQL 및 Redis 서비스를 잠시 중지해 주세요.

## 시작

### 1. 서버 (Server)
* **초기 빌드 안내:** 처음 프로젝트를 클론하여 빌드할 때, `vcpkg`가 종속된 C++ 라이브러리들을 자동으로 다운로드하고 빌드하므로 **약 5~10분 정도 소요**될 수 있습니다.
* **실행 방법:** Visual Studio에서 솔루션을 열어 바로 시작하거나, 빌드 산출물 경로(`bin/x64/...`)로 이동하여 아래의 실행 파일들을 직접 실행해 주세요.
  * `LoginServer.exe`
  * `ChatServer.exe`
  * `MonitorServer.exe`

### 2. 로그인-채팅 더미 클라이언트 (Dummy Client)
서버 부하 및 기능 테스트를 위한 더미 클라이언트입니다.

* **실행 경로:** `IOCPNetModule_MonoRepo\Clients\ChatDummy_Loginserver_20221114\ChatDummy_Login_20221114.exe`
* **사용 방법:** 프로그램을 실행한 후 `0`~`9` 사이의 숫자를 입력하여 접속할 **ID 리스트 그룹**을 선택한 뒤 실행합니다.
> ⚠️ **주의 (다중 실행 시):** 더미 클라이언트를 2개 이상 띄울 때, **서로 같은 ID 리스트 번호를 선택하면 서버에서 중복 접속으로 처리해 클라이언트가 다운(연결 종료) 처리**됩니다. 다중 실행 시에는 반드시 각기 다른 번호를 할당해 주세요.
